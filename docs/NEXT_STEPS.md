# 后续实物验收

v0.0.2 完成软件分层与可测试实现，生产参数和硬件验证仍待完成。

1. 确认F407开发板/HSE8、全部新引脚、卡检测极性、供电与硬件动力急停；先无电机上电。
2. CMSIS-DAP下载验证；测任务栈高水位、200Hz控制WCET/抖动、CAN吞吐和IRQ延迟。
3. TF实际卡：4bit DMA、插拔/超时/坏卡/满卡、长文件名、保存各阶段物理掉电测试。现版本仅启动挂载，异常后重启，不承诺热插拔。
4. OLED型号/地址/字形可读性，TIM3方向/每格计数、按键消抖、上电按住软停、动作中软停实测。
5. HX711 RATE10/80、A128波形、采样噪声、过滤延迟、真实称重传感器量程和安全过载；建立N校准、独立接触阈值与持续时间。
6. 每轴实际ID、正负方向、协议profile、反馈刷新、增益和限幅；六轴建立配置后才允许打开输出门。验证人工STOW摆位重复误差和固定STOW→HOME避碰。
7. 实现并实测CyberGear可控手拖 backend，确认重力支撑/制动；当前保持NOT_CONFIGURED。替换甲方电机按MotorBackend接口，不改业务和轨迹坐标。
8. 采集实际Small/Medium/Large轨迹，逐项确认force hook策略/阈值/结束动作；不以测试HOME轨迹充当生产动作。所有蛋糕尺寸与工艺参数仍TBD。
9. 再评估碰撞、停止距离、掉电重力风险及独立watchdog。尚无碰撞规划、动力学补偿或生产级力控制。
10. 后续需要时增加Pi命令源、J7和挤奶油AUX；当前不实现虚假的设备或工艺逻辑。
