# 使用流程

当前为开发版本，尚未完成实物调试。交付配置会显示“正在连接电机”或“功能尚未就绪”，不会自行运动。以下流程用于完成实物调试后的设备。

## 开机

1. 断开动力并按设备机械说明支撑机械臂，人工放回标记的折叠姿态 STOW。
2. 插入存有动作文件的存储卡，确认运动范围内无人和障碍物。
3. 上电后等待“正在连接电机”及“前往待机”完成。
4. 出现主菜单后，选择“执行动作”或“记录轨迹”。

设备不会自己寻找原点；摆位不正确时不要启动。

## 操作键

- 旋转编码器：上下选择；不使用编码器按压。
- 前进键：进入或确认。
- 后退键：返回；记录中取消并丢弃本次记录。
- 独立软停键：停止当前动作并保持当前位置；不会自动恢复动作。
- 硬件急停：切断动力。使用方式及解除条件按设备电气与机械说明执行。

## 执行动作

“执行动作”内有“回待机”“小蛋糕”“中蛋糕”“大蛋糕”和个人轨迹。蛋糕动作缺少文件时会提示不可用。选择个人轨迹可开始或删除；删除还需要再次确认，默认选“否”。蛋糕动作不能从菜单删除。

个人轨迹需要从对应起点附近开始；不满足时设备拒绝播放，不会突然跳到起点。播放结束后保持最终位置，不自动回待机。停止后的确认只返回菜单，不会续播。

## 记录轨迹

选择“记录轨迹”→“开始记录”。设备先回待机，再进入记录。完成手拖功能调试后才允许人工引导设备；当前开发配置会提示该功能尚未就绪。

前进键结束记录并保存；后退键取消，软停也取消且不保存。屏幕显示时间和容量，约 82 秒达到容量上限，过长会终止并丢弃，因此应提前结束。保存过程中不要拔卡或断电。保存成功后可在动作列表找到新轨迹。

菜单不提供电机、限位、压力或控制参数设置。卡异常后停止使用，断电检查卡并重新上电。
