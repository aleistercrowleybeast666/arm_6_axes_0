# 使用流程

当前为开发版本，尚未完成实物调试。默认配置进入“主菜单[离线]”，可浏览菜单、TF状态和文件；电机/压力未连接不弹窗阻塞。执行/记录前检查依赖，不满足则显示简短错误页，确认或返回后仍在原位置。默认不会自行运动。以下运动流程用于完成实物调试后的设备。

## 开机

1. 断开动力并按设备机械说明支撑机械臂，人工放回标记的折叠姿态 STOW。
2. 插入存有动作文件的存储卡，确认运动范围内无人和障碍物。
3. 上电后等待“正在连接电机”及“前往待机”完成。
4. 出现主菜单后，选择“执行动作”或“记录轨迹”。

设备不会自己寻找原点；摆位不正确时不要启动。

## 操作键

- 旋转编码器：上下选择；菜单中按下进入/确认。子菜单选择末尾“返回”可退回上一层并恢复选中位置。
- 前进键：进入或确认。
- 后退键：返回；记录中取消并丢弃本次记录。
- 运行时编码器按下一次：立即请求软件软停；旋转不改变动作参数。
- 独立软停键：原功能保留，停止当前动作并保持当前位置；不会自动恢复动作。
- 硬件急停：切断动力。使用方式及解除条件按设备电气与机械说明执行。

## 执行动作

“执行动作”内有“回待机”“小蛋糕”“中蛋糕”“大蛋糕”、个人轨迹和“返回”。执行动作的确认页只显示“启动/返回”，默认选“返回”；旋转选“启动”，释放后再次按下才开始。蛋糕动作缺少文件时会提示不可用。选择个人轨迹可开始或删除；删除还需要再次确认，默认选“否”。蛋糕动作不能从菜单删除。

个人轨迹需要从对应起点附近开始；不满足时设备拒绝播放，不会突然跳到起点。播放结束后保持最终位置，不自动回待机。停止后的确认只返回菜单，不会续播。

## 记录轨迹

选择“记录轨迹”→旋转选择“启动”→再次按下（默认“返回”）。设备先回待机，再进入记录。完成手拖功能调试后才允许人工引导设备；当前开发配置会提示该功能尚未就绪。

前进键结束记录并保存；后退键取消。编码器按下或专用软停均取消且不保存。屏幕显示时间和容量，约 82 秒达到容量上限，过长会终止并丢弃，因此应提前结束。保存过程中不要拔卡或断电。保存成功后可在动作列表找到新轨迹。

菜单不提供电机、限位、压力或控制参数设置。卡异常后停止使用，断电检查卡并重新上电。

## 未接电机/压力时调菜单与TF

主菜单仅四项：执行动作、记录轨迹、TF卡、设备状态；一行标题加三行内容，旋转分页，选中反白。TF卡下可浏览个人轨迹、看卡状态、刷新已有挂载卡的列表。离线也可删除个人轨迹，完整文件名分两行显示，确认默认为“否”；工厂动作不能删除。未提供格式化或自动擦卡。记录保存仍依赖真实反馈及可控手拖，当前真实backend未配置。

设备状态只展示实际电机配置/反馈和压力采样/校准状态；再按确认查看固件版本、MCU和输出门。不会把菜单可用显示为电机READY；动作开始前还会在控制层核对安全条件。压力无数据、过期或未校准不显示就绪。菜单不提供生产参数编辑或持久化设置。

按住不会重复确认。停止后先释放编码器，再按下只确认停止并返回，不会续跑；再次启动仍需重新选择“启动”并按下。报错按确认/返回回到原位置。参数编辑功能本轮未新增。
