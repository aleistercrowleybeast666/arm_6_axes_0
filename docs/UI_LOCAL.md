# 本地 UI

当前软件按 SSD1306、I2C2 0x3C、128×64 实现，旧硬件设计也写明1.3寸128×64。用户已反馈型号确认及前一版菜单实物可用；本轮只离线验证新增编码器交互，没有进行新的硬件测试。

固定四行16px：第一行标题及页码（超过三项时），下三行内容；标题下划线，选中整行反白。中文16×16单元，英文数字8×16单元，同一Noto黑体风格和基线；不切换字号。只有选中的长ASCII文件名横向滚动，初始停留约900ms，每300ms前进一字符。删除确认将完整31字节文件名分两行显示，最后一行用方括号标出当前选择，默认[否]。

```text
主菜单（未完成启动时标题带[离线]）
  执行动作 -> 回待机 / 小中大蛋糕 / 个人轨迹 / 返回
  记录轨迹 -> 启动 / 返回（默认返回）
  TF卡 -> 浏览文件 / 卡状态 / 刷新列表 / 返回
  设备状态 -> 电机/压力状态；系统信息 / 返回
个人轨迹 -> 启动（进入启动确认） / 删除 / 返回
删除确认 -> 完整文件名；[否] 是
回待机/个人轨迹确认 -> 启动 / 返回（默认返回）
蛋糕动作确认 -> 启动 / 返回（默认返回，不叠加确认层）
文件列表/卡状态/系统信息 -> 末尾返回
```

打开和浏览不检查电机/压力，不以STARTUP_READY作为菜单入口条件。BOOT/WAIT_MOTORS/FAILED均可浏览；正在STOW→HOME或实际操作中仍显示状态页。执行或录制入口离线标[X]，选择时返回简短原因，确认/返回后保留原页面和选择。UI不建立虚假READY；OperationManager的运动安全门及默认输出锁均保留。工厂动作的压力依赖仍由Recipe与ForceCondition检查，当前真实手拖backend保持NOT_CONFIGURED。

TF浏览使用StorageSnapshot，UI不直接操作FatFs。刷新和确认后的个人轨迹删除通过LOCAL CommandManager进入OperationManager的storage_only维护路径，只允许安全空闲状态。其结果由StorageTask独占处理，失败有状态页，确认后返回原位置；该路径不使能电机、不捕获零位、不调用运动。只刷新已挂载卡，无格式化/热插拔/自动重挂载；IO失败后仍按原约定重新上电。参数设置及新参数保存接口本轮未添加，原校准文件仍保留CRC/临时文件验证流程。

输入：TIM3 PA6/PA7旋转，默认4counts/detent；PC4编码器按键在菜单进入/确认，运行时只触发软停。前进PE9在菜单仍确认、记录中完成并保存；后退PE10仍返回/取消、记录中取消。PE11专用软停仍走原有独立中断与控制链，不用于导航，优先级不变。硬件急停独立切断动力。没有组合键、双击或长按功能。

全部子菜单可旋转选中末尾“返回”并按下回到父菜单；删除确认的“否”同样取消返回。静态五层返回栈保存父菜单选中位置和滚动进度，返回恢复，目录变化时重新限制有效选择。动作确认统一默认“返回”；选择“启动”后，必须新的按下事件才能提交，提交时和控制层均再次检查依赖。没有新增参数编辑器。

编码器事件与前进键分开；在动作加载、待提交启动、STOW→HOME、执行、等待压力或记录时，编码器按下优先于页面焦点和错误提示，经App_RequestSoftStop直接锁存、清空旧业务命令，控制任务走现有OperationManager_SoftStop，不经过业务队列或确认页。运行时旋转不改变动作参数。记录软停丢弃本次记录，保存仍用原前进键。停止后新的按下只确认/返回，不恢复播放；再次启动重新经过默认返回的确认页。

按键稳定按下和释放均25ms消抖，每次按住只产生一次事件，启动时已按住必须先释放。切页、提交命令或启动/运行/停止状态变化时清掉残留旋转计数；保留已消费按下的释放锁，避免弹跳穿透为启动、软停或再次启动。状态变化期间一个尚未消费的新按下仍可完成消抖触发软停，不丢失新停机请求。UI接受编码器事件后立即锁存软停；这不是硬件急停，真实按键到停止的延迟、OLED发送阻塞和受控停止距离仍需实物验证。

UiTask输入10ms、显示20Hz，I2C单次10ms超时；掉线初始化重试500ms。HX711读取无数据立即返回，StorageTask独占挂载及有界SDIO IO，缺失外设不会等待在控制/菜单入口。显示1KiB framebuffer，字库子集为静态const，无heap。UiRaster为生产显示和host验证共用的纯位图渲染器，SSD1306 backend只负责有界I2C发送。

CAN Start或通知启用失败不再在App_Init停死；保留静态RX队列保证CanRxTask有界等待，故障锁存到输出门，设备页显示CAN未就绪。此软件降级不会把总线恢复或电机状态标成正常。

本次仅离线构建、host模拟和实际C帧缓冲图像检查；没有连接串口/SWD、电机、压力模块或真实TF卡，未烧录/复位。用户先前的OLED实物反馈不等于本轮新增编码器软停已实测；新交互及真实停止行为仍NOT TESTED ON HARDWARE。
